# 📍 Achei em Pilar — Guia Comercial Local

O Guia Comercial e de Serviços de **Chã do Pilar & Pilar Centro (Alagoas)**.

## 🚀 Funcionalidades
- 🔍 Busca rápida em tempo real por produtos e categorias (lanches, bolos, fretes, farmácias, barbearias, roupas, variedades).
- 🏷️ Filtros por Bairro (Chã do Pilar, Pilar Centro, Chã Elias, Imburi).
- 📲 Botões oficiais para WhatsApp, Instagram e localização no Google Maps.
- 📸 Fotos e logomarcas oficiais dos estabelecimentos.
- 🛡️ Painel Administrativo protegido por PIN para cadastro, edição e exclusão de comércios.
- 📱 100% Responsivo e otimizado para celulares (Mobile First).

## 💻 Tecnologias
- HTML5 / Vanilla JavaScript
- Tailwind CSS
- Lucide Icons
